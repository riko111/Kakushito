かくしーと プライバシーポリシー

```

制定日：2026年8月20日

1. はじめに

本プライバシーポリシーは、「かくしーと」（以下「本アプリ」）における ユーザーの情報の取り扱いについて定めるものです。

2. 収集する情報

本アプリは、現在のバージョンにおいて、ユーザーを特定できる個人情報を 収集しません。

本アプリでは、ユーザーが選択したPDFファイルや、本アプリ上で作成した マーカーなどの学習データを、アプリの機能を提供するために端末上で 取り扱います。

3. 情報の利用

端末上で取り扱うPDFファイルや学習データは、本アプリの学習機能を 提供する目的でのみ使用します。

現在のバージョンでは、これらのデータを本アプリの開発者が収集したり、 外部のサーバーへ送信したりすることはありません。

4. 第三者への提供

本アプリは、現在のバージョンにおいて、ユーザーの個人情報を 第三者に提供、販売、共有することはありません。

5. 外部サービス

本アプリの現在のバージョンでは、広告配信、アクセス解析、 クラッシュレポートなどを目的とした外部サービスを利用していません。

6. データの保存と削除

本アプリが端末上で取り扱うPDFファイルや学習データについては、 ユーザー自身が端末上で管理および削除することができます。

本アプリの開発者は、現在のバージョンにおいて、ユーザーの学習データを 外部サーバーに保存していません。

7. セキュリティ

本アプリは、現在のバージョンにおいて、ユーザーのデータを 外部サーバーへ送信する機能を提供していません。

8. 本ポリシーの変更

本アプリの機能変更やサービス内容の変更などに伴い、 本プライバシーポリシーを変更する場合があります。

変更した場合は、本ページに掲載することでお知らせします。
